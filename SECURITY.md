
# Security Policy

## Supported Versions

NeoAsmara is currently in active development. Security fixes are applied to the latest development release.

| Version | Security Updates |
| ------- | ---------------- |
| 0.0.2   | Supported |
| 0.0.1   | Not supported |

Older builds may contain bugs or vulnerabilities already addressed in newer versions.

## Reporting a Vulnerability

If you discover a security vulnerability in NeoAsmara, please report it privately.

You can contact the project maintainer through our Discord community:

https://discord.gg/t6Udbt773

Please avoid posting exploit details, sensitive information or vulnerabilities that could affect running servers in public channels.

When reporting an issue, include the affected version, a description of the vulnerability and steps to reproduce it, if available.

## Security Updates

Confirmed vulnerabilities will be reviewed and addressed in future Core updates.

NeoAsmara is still a development project. Security fixes and response times are not guaranteed.
